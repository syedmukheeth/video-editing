# Strict rules for this repository

These rules apply to every session, local or cloud, and override any default attribution
behaviour. They are not optional.

## 1. Commit and PR attribution

- **Never** add Claude (or any AI model) as a co-author. Do not add
  `Co-Authored-By: Claude …` or any other Claude/Anthropic trailer to commit messages.
- Do not add Claude attribution lines of any kind: no `Claude-Session:` links in commits, and
  no "Generated with Claude Code" (or similar) lines in pull request titles or descriptions.
- The only co-author trailer allowed on commits is:

  ```
  Co-Authored-By: Saad Ahmed <sahmed.9@hotmail.com>
  ```

- This applies to commits made locally and in cloud sessions, on every branch.

## 2. Purpose of the repository

- This repository is **for research purposes only**.
- Do not present it as a production, commercial or monetized product, and do not add billing,
  payment or commercial-service features.
